# AquaQuest

**AquaQuest Development Roadmap**

Engine: Godot 4.5
Platform: Android
Genre: 2D Top-Down Educational RPG
Research Focus: Dynamic Difficulty Adjustment (DDA)
Target Users: FASD Students of CvSU-Naic

**AquaQuest Game Loop**
Talk to NPC

    ↓
    
Accept Quest

    ↓
    
Go to Fishing Area

    ↓
    
Cast Rod

    ↓
    
Fish Bites

    ↓
    
Question Appears

    ↓
    
Answer Correctly

    ↓
    
Catch Fish

    ↓
    
Return to NPC
    ↓
Complete Quest
    ↓
Receive Reward
